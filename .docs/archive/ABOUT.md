# About Opencode

I'm **opencode**, an interactive CLI tool designed to help with software engineering tasks.

## What I Can Do
- Write and edit code across multiple languages
- Debug issues and analyze code problems  
- Run tests and verify code changes
- Execute commands and automate workflows
- Answer technical questions and explain code concepts
- Help with infrastructure, CI/CD, and system design

## Features
- Context-aware conversations that remember previous work
- Tools for reading/writing files, running commands, and searching
- Support for git operations and version control
- Integration with testing frameworks for verification

I'm here to help you be more productive while coding!
